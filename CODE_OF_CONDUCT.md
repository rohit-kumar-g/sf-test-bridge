# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive. Harassment, personal attacks, discriminatory language and publishing other people's private information are not accepted, in issues, pull requests or anywhere else in the project.

**Never post customer data, org addresses, usernames or debug logs from a real org** in an issue or pull request. Scrub them first.

Report unacceptable behaviour privately to the maintainer through the repository's [private reporting form](https://github.com/rohit-kumar-g/sf-test-bridge/security/advisories/new) (it accepts any confidential report, not only security issues). Reports are handled confidentially. The maintainer may remove content and block participants who don't follow this code.
